# Separate future work

Fo4 Dismemberment Validator is a proposed standalone authoring utility: inspect NIF segment/subsegment and cut-offset metadata, validate relationships, and create/merge named SSF entries while preserving existing definitions. It is not implemented here and does not belong in the F4SE runtime plugin. Asset rights and references must be respected.

OG 1.10.163 support is a separate future compatibility investigation. No OG metadata, profile or shader substitution is enabled in either release configuration.
